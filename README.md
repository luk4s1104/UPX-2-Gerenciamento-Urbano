# 🏙️ Cidade Melhor

**Sua cidade, nossa responsabilidade.**

O **Cidade Melhor** é um site criado para que os moradores de Sorocaba-SP possam ajudar a cuidar da sua cidade. Sabe aquele buraco na rua, aquela calçada quebrada ou aquele bueiro vazando esgoto que todo mundo vê, mas ninguém sabe como avisar a prefeitura? O nosso site resolve isso de um jeito visual, simples e transparente. 

O projeto foi desenvolvido como um trabalho acadêmico para a disciplina **UPX 2 – Desenvolvimento Sustentável** do curso de Engenharia da Computação.

---

## 🌟 Como o Site Funciona?

O site funciona como uma rede social de problemas urbanos, onde existem dois tipos de usuários: o **Cidadão** e o **Gestor Público (Prefeitura)**.

1. **O Cidadão reporta:** Você anda pela rua, vê um problema, entra no site e marca o local exato em um mapa. Você dá um título, descreve o que está acontecendo e pode subir até 3 fotos.
2. **A comunidade apoia (Upvote):** Outros moradores que passam pelo mesmo lugar podem clicar em "Confirmar problema". Quando um problema alcança **20 ou mais confirmações**, ele ganha um selo de **"Em Alta"** e fica maior no mapa para chamar a atenção.
3. **A prefeitura resolve:** O gestor da prefeitura tem uma senha especial. Ele consegue olhar o mapa, ver quais problemas são mais urgentes (os mais votados) e mudar o status (ex: de "Reportado" para "Em análise", depois "Em andamento" e, finalmente, "Resolvido").
4. **Histórico Transparente:** Quando a prefeitura resolve um problema, ele vai para uma linha do tempo pública, onde todos os moradores podem comemorar as melhorias conquistadas.

## 📝 O que você encontra em cada página do site?

* **Página Inicial (`index.html`):** Explica o projeto, mostra quantos problemas já foram resolvidos e traz um painel com os casos mais urgentes da cidade.
* **Mapa Geral (`mapa.html`):** Um mapa interativo de Sorocaba cheio de pins coloridos. Cada cor é uma categoria (Amarelo é buraco, Roxo é lixo, Verde é iluminação, etc.). Você pode filtrar para ver só o que te interessa.
* **Fazer uma Reclamação (`reportar.html`):** A página onde você clica no mapa para o site descobrir o endereço sozinho e preenche os dados do problema com fotos.
* **Página do Problema (`ocorrencia.html`):** Mostra os detalhes de uma reclamação específica, a linha do tempo do status e uma área de comentários para os vizinhos conversarem.
* **Meus Pins (`meus-pins.html`):** A sua área privada. Mostra todos os problemas que você já cadastrou e se a prefeitura já começou a mexer neles.
* **Painel de Conquistas (`resolvidos.html`):** O "Changelog" da cidade. Uma lista bonita que mostra tudo o que já foi consertado mês a mês.
* **Gráficos e Estatísticas (`relatorios.html`):** Gráficos que mostram de forma transparente quais são os problemas mais comuns em Sorocaba e a velocidade de resposta da prefeitura.
* **Espaço Educativo (`sustentabilidade.html`):** Explica o que são os ODS (Objetivos de Desenvolvimento Sustentável) da ONU e dá dicas de pequenas ações que nós podemos fazer no dia a dia.
* **Sobre a Equipe (`sobre.html`):** Mostra quem são os alunos que criaram o site e tem um botão mágico para "Restaurar os dados de teste".
